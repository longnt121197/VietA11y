# VietA11y screenshots

This directory contains real screenshots of the released application. Do not
add mockups or invented scan results.

The current desktop screenshot set shows:

1. the scanner input page;
2. the summary from a completed accessibility report; and
3. the curated Vietnamese guidance for the `image-alt` finding.

These images were captured from the production build with the repository's
deterministic `web-e2e` fixture and exact trusted-local-fixture test seam. The
report crops intentionally exclude the loopback fixture URL.

Before adding an image, remove private URLs or page data, use a deterministic or
maintainer-controlled target, keep text legible, and provide useful alt text in
the README. Prefer a compact web-friendly format and avoid decorative captures
that do not help a new visitor understand the project.
