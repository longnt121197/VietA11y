# VietA11y screenshots

This directory is reserved for real screenshots of the released application.
Do not add mockups or invented scan results.

The initial screenshot set should show:

1. the scanner input page;
2. a completed accessibility report; and
3. one curated Vietnamese guidance example.

Before adding an image, remove private URLs or page data, use a deterministic or
maintainer-controlled target, keep text legible, and provide useful alt text in
the README. Prefer a compact web-friendly format and avoid decorative captures
that do not help a new visitor understand the project.
