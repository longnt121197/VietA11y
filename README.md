# VietA11y

> Vietnamese Web Accessibility Scanner & WCAG Checker

VietA11y is an open-source accessibility testing tool
built for Vietnamese developers.

It helps developers scan websites for accessibility issues,
understand WCAG violations in Vietnamese,
and learn how to fix them.

## 🚧 Project Status

VietA11y is currently under active development.

Our first milestone is an MVP web accessibility scanner
powered by Playwright and axe-core.

## 🎯 Goals

- Scan websites for accessibility issues
- Explain WCAG violations in Vietnamese
- Provide practical remediation examples
- Build a Vietnamese accessibility knowledge base
- Provide reusable tooling for CLI and CI workflows
